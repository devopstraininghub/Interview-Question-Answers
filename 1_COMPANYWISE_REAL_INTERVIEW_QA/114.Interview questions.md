**Q3. From your perspective, what are the top three responsibilities of an SRE role?**

**A:** 

1. Ensuring service reliability and availability through monitoring, working with SLAs and SLOs, responding to incidents and reducing MTTR.
2. Improving automation and scalability through CI/CD, infrastructure as code using Terraform and deployment automation.
3. Preventing recurring issues through root cause analysis, observability improvements and documentation so that others can resolve similar issues.

**Q4. What are the top three skills needed for an SRE role?**

**A:** First, strong troubleshooting and incident response skills to restore services quickly and reduce MTTR.

Second, automation and infrastructure skills using tools such as Terraform, Ansible, Jenkins, Kubernetes and AWS cloud services.

**Q5. If a website or application is slow, what are the top four things you would check?**

**A:** First, I check monitoring for latency, error rate and traffic. I also check CPU, memory, disk space and whether the network is correctly routed.

If requests are slow after a deployment, I check whether the APIs are working correctly. I also check the load balancer and whether the correct load is distributed. If required, scaling can be performed.

**Q6. How would you check whether there is an API failure for a website?**

**A:** I check the application API logs for HTTP errors such as 400 or 500, timeout messages and slow response times.

I review application latency, request rate and error rate on monitoring dashboards. I can test endpoints directly using tools such as `curl`.

I also verify DNS, ports, security groups and whether the load balancer target health checks are working correctly.

**Q13. Suppose you start working independently with US teams and expectations increase, requiring you to work beyond 2 AM and sometimes until 4 AM for more than two weeks. What would you do?**

**A:** First, I would understand whether the delay is caused by my work or by something on the other person's side.

If my work is pending, I would consider staying back to complete it. If it is not related to my work, I would discuss the workload, priorities and deadlines with my manager.

I would understand whether the extended hours are temporary or ongoing and discuss the impact with my manager. I would also establish a clear cutoff and handoff process.

For urgent issues, I would support the team based on the priority and situation.

**Q14. If a new project is assigned to you and you feel it will increase your workload, what would be your approach?**

**A:** I would review the new project's priority, deadlines and required effort before accepting the work.

I would discuss the impact with my manager and explain my current workload, working hours and existing responsibilities. I would ask for priority adjustments and create a clear plan for the new work.

I would communicate with the US teams as well. I can support urgent work, but I would not allow continuous overtime.
