### Q2. What is the difference between a soft link and a hard link?

**A:** A soft link is a separate file that stores the path to another file or directory. It can point across different file systems and can also point to directories. If the original file is deleted or moved, the soft link becomes broken.

A hard link is another directory entry pointing to the same inode and data as the original file. Deleting the original file does not remove the data while the hard link still exists.

### Q3. What is the difference between SIGTERM (signal 15) and SIGKILL (signal 9)?

**A:** SIGTERM (signal 15) requests a process to terminate gracefully. The process can catch the signal and finish cleanup tasks, close files, release resources, and then exit.

SIGKILL (signal 9) immediately stops the process. The process cannot catch, ignore, or handle this signal, so it cannot perform cleanup tasks.

### Q4. How can you identify which process is consuming high CPU?

I first confirm whether the CPU usage is sustained or just a short spike. I use `top` and press `Shift + P` to sort processes by CPU usage. Then I monitor the process at several intervals and record its CPU usage, for example, every five seconds.

### Q6. What is load average, and how can you interpret it?

**A:** Load average shows the average number of processes that are running or waiting for CPU or uninterruptible I/O over three time periods: 1 minute, 5 minutes, and 15 minutes.

I can check it using the `uptime` command. The `w` command also displays the load average. We can also see the load average at the top of the `top` command output.

### Q7. How do you troubleshoot a Linux server when disk space is full?

**A:** First, I confirm which file system is full using the `df -h` command.

I also check inode usage using `df -i`, because a file system can run out of inodes even when disk space is available.

Then I identify the directories consuming the most space using `du` and sorting commands. I look for large logs, temporary files, old packages, and application-generated files.

I also check for deleted files that are still held open by running processes. If I find an open deleted log file, I restart the owning service through the approved procedure to release the space.

I safely clean temporary files, rotate or compress logs, remove unused packages, and extend the file system when required. After cleanup, I verify the available space.

### Q8. What is swap memory?

**A:** Swap memory is disk space that Linux uses as virtual memory when physical RAM becomes low.
