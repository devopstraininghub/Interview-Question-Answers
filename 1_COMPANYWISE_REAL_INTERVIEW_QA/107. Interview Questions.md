### 5. In Ansible, what are the different ways to provide inventory files to a playbook?

**Answer:**

Ansible supports static and dynamic inventories.

The default inventory file is `/etc/ansible/hosts`. Static inventory contains manually defined servers.

I have also worked with dynamic inventory, where multiple inventory sources can be used. For example, I use the AWS EC2 inventory plugin to discover EC2 instances.

### 6. What is the precedence if we mention an inventory in the Ansible configuration file and also provide it through the command line?

**Answer:**

The command-line inventory takes higher precedence and overrides the inventory configured in the Ansible configuration file.

### 7. Which option do we need to provide while using command-line inventory?

**Answer:**

I use the `--inventory` option.

For example:

`ansible-playbook --inventory <inventory-file> <playbook-file>`

### 20. Suppose you want to upgrade application servers without affecting traffic or requests. You have a load balancer in front of five application servers. How would you approach this?

**Answer:**

I would use a rolling deployment strategy.

First, I would verify that all five application servers are healthy and that the remaining four servers can handle the application traffic.

I would configure connection draining on the load balancer.

Then I would deregister the first application server from the target group so that it stops receiving new requests.

I would deploy the new Java files using Ansible and restart the application, such as Tomcat, if required.

I would verify the deployed application version and application logs.

After that, I would perform health checks to confirm that the application is working correctly.

Once the server is healthy, I would register it again with the load balancer and wait until the target status becomes healthy.

### 23. What is the difference between modules and manifests in Puppet?

**Answer:**

In Puppet, a manifest contains the desired configuration of a server.

It defines how to install applications, create users, manage files, and start services.

For example, a manifest can define how to install Apache and ensure that the service is running.

A module is a collection of related configuration files, manifests, and templates organized together.

### 27. Suppose a log file is consuming a lot of disk space. You delete, truncate, or zip the file, but the system still shows 100% disk usage. What could be the reason?

**Answer:**

First, I would check disk space using:

`df -h`

I suspect that a running process is still holding the deleted log file open.

The filesystem removes the file, but the disk space remains allocated until the process closes the file descriptor.

I would check the running processes and identify whether an application is holding the deleted file.

If required, I would restart the particular application and check the disk space again using `df -h`.
